新手起步與安全設定

先把畫面、備份、GM 權限與基本操作處理好，後續不論要仿正農裝或爽玩指令都會穩定許多。

Start Route

畫面與介面

建議解析度先調成 1920 x 1080，再依螢幕微調。狀態列與皮膚可在 ESC 的遊戲設定中更換，服飾外觀則用 Alt+Q 打開特殊裝備後，啟用僅展示時裝。

Setup_PlusAlt+QESC 設定

修改前一定備份

Server\conf 與 Server\db\re 都是核心設定區。改 skill_db、item_db_equip 或設定檔前先備份；若技能檔改壞導致遊戲開不了，把備份覆蓋回 Server\db\re 後重開伺服器。

帳號與角色

隨便建立帳號即可視為 GM。原始 GM 帳號可用 admin / admin，適合拿來組隊或測副本。組隊可用 /organize 組隊名稱。刪除角色時信箱欄不用輸入，直接確認即可；角色位置可用右鍵預約移動再移到空位。

掛機遇王就飛

若內掛 / 外掛想遇到 MVP 就飛，可到 battle_conf.txt 找「是否啟用遇見 MVP 時，視為攻擊目標」相關設定，將 off 改成 on。實際欄位名稱依版本翻譯可能略有不同。

若指令沒有反應，先重登角色。若製作出的道具出現紅字或會造成閃退，立刻前往 @mapmove prt_in 286 128 找刪除 NPC 清掉。

仿正玩法與倍率設定

想保留成長感時，可把倍率、商城幣與便利功能調成接近正服的節奏；想輕鬆玩則保留 GM 指令快速補足。

點擊指令膠囊可複製。這些指令是起步、練功、測試、倉庫、轉職與外觀調整最常用的工具。

起步資源

飛中央； 加快移動； 取得金錢； 取得商城點。

補給與倉庫

補 HP/SP； 補 AP； 開倉； 遠端倉庫貓咪。

角色成長

提升 Base； 提升 Job； 學所有技能； 轉盧恩龍爵。

屬性與四轉素質

@STR 99、@AGI 298、@VIT 999 可調六圍；四轉特殊素質可用 @POW 100、@STA、@WIS、@SPL、@CON、@CRT。

傳送與紀錄

@mapmove 地圖 座標 可指定飛行，例如 @mapmove prontera 149 102 找仙境傳送員；到喜歡的位置後用 @save 存復活點。

寵物與坐騎

@mount2 上下坐騎；@hatch 孵蛋；@petfriendly 1000 親密滿；@pethungry 100 飽足滿；騎士龍色可用 @ccolor 0 到 7。

變身與召喚

@disguise 怪物ID 變身；@undisguise 復原；@monster 怪物ID 召喚怪；觀光可用 @HIDE 隱形避怪。

天氣與刷新

@snow、@clouds、@fog、@sakura、@leaves 可切換天氣；@reloadscript 可刷新腳本或怪物。

自動檢取與刷材料常用指令

@autoloottype +2 撿消耗品、+3 戰利品、+4 防具、+5 武器、+6 卡片。打王時可關閉卡片自動撿取，保留王卡噴出的爽感。刷幣可用 @rura gl_dun02 狂暴米諾斯牛環、@rura mjolnir_03 黑蛇蛇鱗、@rura dew_dun02 伊斯坦納洞穴打鋁。
